# S ABROAD — архив для Claude Code

## Как запустить
1. Распакуйте архив в пустую папку.
2. (Лучше сразу) откройте `content/site.json` и замените строки `TODO…` на реальные данные: номер WhatsApp, телефон, домен сайта. Можно и потом — сайт соберётся с заглушками, а Claude Code в конце выведет список того, что осталось заполнить.
3. Если есть настоящий логотип — положите его в `assets/logo.svg` (или .png).
4. Откройте папку в терминале, запустите `claude` и напишите: **делай**

Claude Code прочитает `CLAUDE.md` и соберёт сайт в папке `site/`: сам проверит мобильную и десктопную версии по скриншотам и выдаст отчёт.

## Что внутри
- `CLAUDE.md` — главная инструкция и план работы
- `docs/` — бриф, дизайн, техника, чек-лист приёмки
- `content/site.json` — контакты, ссылки, города на табло
- `content/i18n/` — все тексты на RU / KZ / EN / CZ
- `assets/` — временный знак и favicon
- `.claude/settings.json` — разрешает npm/npx без лишних подтверждений

Нужен Node.js 20+.
