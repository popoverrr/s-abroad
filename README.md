# S ABROAD — правки v4 (пасхалка «поймай самолётик») для Claude Code

Распакуйте архив **поверх папки проекта** с заменой файлов, откройте её в терминале → `claude` → напишите **делай**.

Архив заменяет только `CLAUDE.md` и добавляет `docs/07-easter-egg-v4.md` и папку `egg/` с готовой анимацией. Код сайта, тексты и контакты он не трогает.

Посмотреть анимацию до встраивания: откройте `egg/demo/demo.html` в браузере. Фон там условный — смотрите на самолётики. Кликните по странице, чтобы включился звук, и нажмите «Запустить ещё раз».
