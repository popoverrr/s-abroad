# S ABROAD — правки v2 для Claude Code

## Как применить
**Вариант А (у вас есть папка проекта с v1):** распакуйте архив **поверх** этой папки с заменой файлов. Будут заменены `CLAUDE.md`, `content/`, `docs/`, добавлены `assets/brand/` и новый `assets/favicon.svg`. Папку `site/` архив не трогает.

**Вариант Б (папки нет):** распакуйте в пустую папку. Claude Code попробует склонировать репозиторий `popoverrr/s-abroad` в `site/`; если не выйдет — соберёт заново уже с правками.

Дальше: откройте папку в терминале → `claude` → напишите **делай**.

## Что в правках
1. Штампы — чёткие: убраны фильтры, из-за которых было мыло.
2. Украинский филиал и Telegram удалены.
3. Главная кнопка «Написать в WhatsApp» открывает выбор между двумя менеджерами — Рамиль и Гайнель. У каждого менеджера есть прямые кнопки WhatsApp и звонка (1 тап).
4. Добавлены Instagram, TikTok и Threads. Настоящий логотип в векторе, палитра переведена на брендовый зелёный #195231.
5. Юзабилити: на телефоне кнопка WhatsApp видна сразу, без скролла. Язык переключается в 1 тап, вступительной анимации нет, лишний декор перед кнопками убран.
