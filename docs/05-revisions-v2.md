# 05 — Правки v2 (приоритет выше, чем у 01–04)

Живая версия v1: https://popoverrr.github.io/s-abroad/ (GitHub Pages, base `/s-abroad/` — не сломай).
Если что-то в 01–04 противоречит этому документу, прав этот документ.

## Главное требование клиента
> «Для визитки сложно. Упрости юзабилити: минимум кликов, минимум скролла, просто визитка. Визуал не упрощай — оптимизируй визуал под юзабилити».

Концепция «посадочный талон», табло, глобус и штампы **остаются**. Меняется иерархия: сначала действие, потом атмосфера.

### Что было не так в v1 (замерено на живом сайте)
- Мобильный 390×700: первый экран — это только слоган, табло и начало талона. Кнопка WhatsApp находится примерно на 1,4 экрана вниз. **Это главный баг.**
- В талоне до первой кнопки идут маршрут ALA→EUR (крупно), строка «Пассажир/Класс/Посадка» и заголовок «Выходы». Всё это декор перед действием.
- Язык на мобильном — выпадающий список, то есть два тапа.
- Под штампами длинные описания, штампы в горизонтальной прокрутке — лишний скролл.
- Штампы мыльные (см. п. 1).

### Бюджет кликов и скролла (проверяется тестом)
| Действие | Мобильный | Десктоп |
|---|---|---|
| Написать в WhatsApp конкретному менеджеру | 1 тап (иконка WA у менеджера) или 2 (главная кнопка → имя) | то же |
| Позвонить менеджеру | 1 тап | — (на десктопе `tel:` показываем, но акцент на WA) |
| Открыть Instagram / TikTok / Threads | 1 тап | 1 клик |
| Сменить язык | 1 тап | 1 клик |

Видимость без скролла:
- **360×640 и 390×664** (окно Instagram in-app browser): главная кнопка «Написать в WhatsApp» **целиком видна на первом экране**.
- **390×844**: на первом экране видны главная кнопка + оба менеджера + ряд соцсетей.
- Вся мобильная страница — **не больше 1,6 высоты экрана** на 390×844.
- **Десктоп 1280×800 и 1920×1080**: всё на одном экране, скролла нет (как и было).

## 1. Штампы — чёткие (жалоба: «как будто в 144p»)
Причины в v1 (проверено в DOM): `feTurbulence + feDisplacementMap` и маска-«крапинки» на группе; `filter: drop-shadow(…14px)` на обёртке; `opacity: .92` на svg; viewBox 132, отрисованный в 143.6px (дробный масштаб); текст по кругу 9,5px; CSS-поворот обёртки с фильтром. Всё это растеризует и мылит штамп.

Как надо:
- **Удалить все SVG-фильтры** у штампов (turbulence, displacement, speckle, colorMatrix) и CSS `filter`/`drop-shadow`/`backdrop-filter`/`blur` на штампах и их предках. Свечение, если нужно, — отдельным слоем **позади** штампа (радиальный градиент в `::before`), а не фильтром на нём.
- `opacity: 1`, цвет сплошной. Никакого `will-change`, `transform: translateZ`, `scale` в покое. Поворот задавай **внутри SVG** (`<g transform="rotate(-8 100 100)">`), а не CSS-трансформом обёртки. Анимация появления допустима, но в конце у обёртки `transform: none`.
- `viewBox="0 0 200 200"`; рендер-размер — целые пиксели, кратные 4: **112px** десктоп, **76px** мобильный.
- Обводки: внешнее кольцо 4 ед., внутреннее 1.5 ед., `vector-effect` не нужен; `shape-rendering="geometricPrecision"`, `text-rendering="geometricPrecision"`.
- Текст по кругу (`textPath`): Onest 600, **font-size ≥ 18 ед.** (≈10px при 112px), `letter-spacing: 2`, uppercase, строка из i18n `services[i].ring` + « • », повтор по окружности. На **мобильном (76px) текст по кругу не рисовать** — только двойное кольцо, иконка и название под штампом.
- Иконка в центре — линейная, stroke 5 ед. (≈2.8px при 112px), `stroke-linecap="round"`.
- Название услуги — **под штампом обычным HTML-текстом** (12–13px, Onest 500), а не внутри SVG: так оно всегда резкое и не обрезается (в v1 «ПОСТУПЛЕНИЕ» обрезалось).
- «Чернильность» без мыла: 6–10 маленьких прозрачных «выщерблин» — чёткие круги/штрихи в `<mask>` (детерминированные координаты), без шума.
- Цвета на тёмном фоне: чередовать `--gold` и `--mint` (см. п. 5), обе сплошные.
- Описания под штампами (`services[i].text`) **удалить**. Штампы некликабельные (`<div>`, не `<a>`), без hover-подсказок. Это визуальный список услуг.
- Раскладка: **4 в один ряд** везде, без горизонтального скролла. На мобильном `grid-template-columns: repeat(4, 1fr)`, штамп 76px по центру ячейки.
- Проверка: скриншот с DPR 3, кроп 4× на один штамп → края колец и буквы резкие, без ореолов и «шума». Приложи этот кроп в `screenshots/stamp-zoom.png` и посмотри на него.

## 3. Менеджеры и выбор в WhatsApp
Данные — `site.json → managers`: **Рамиль** +7 707 585 87 47, **Гайнель** +7 701 800 90 45 (имена — из i18n `managers.*`).

### Главная кнопка «Написать в WhatsApp»
- Первый элемент талона. Во всю ширину, высота 60px, фон `--brand`, текст белый, иконка WhatsApp слева, подпись `cta.primary`, под ней мелко `cta.primary_sub`.
- По нажатию открывается **выбор менеджера** (`chooser`):
  - Мобильный (<768): bottom sheet, высота по контенту, фон `--paper`, ручка сверху, заголовок `chooser.title`, подзаголовок `chooser.sub`, **две большие строки** (min-height 72px): аватар-кружок `--brand` с инициалом, имя крупно, телефон мелко, справа иконка WhatsApp. Тап по строке → сразу `https://wa.me/<номер>?text=<wa.default с подставленным {name}>`, лист закрывается.
  - Десктоп: поповер под кнопкой (или над, если не помещается), те же две строки.
  - Закрытие: тап по фону, Esc, свайп вниз (мобильный), системная кнопка «назад» на Android (push `history.state` при открытии, закрытие на `popstate`).
  - Анимация открытия ≤ 200 мс, фокус на первую строку, focus trap, `role="dialog"`, `aria-modal`.
  - Если WhatsApp открывается в новой вкладке на десктопе — `target="_blank" rel="noopener"`; на мобильном — без target.

### Блок менеджеров (сразу под главной кнопкой)
- Заголовок-лейбл mono `managers.title`.
- Две строки (мобильный) или две колонки (десктоп, если в талоне ≥ 420px, иначе строки): аватар 40px с инициалом, имя (Onest 600, 17px), телефон форматированный (`+7 707 585 87 47`), справа **две круглые кнопки 44px**: WhatsApp (заливка `--brand`, белая иконка) и телефон (обводка). `aria-label` из `actions.wa_to` / `actions.call_to` с `{name}`.
- Номер телефона — тоже ссылка `tel:`.

### Sticky-CTA (мобильный)
Остаётся, открывает тот же chooser. Показывается, только когда главная кнопка ушла из вьюпорта. Фон `--paper`, текст `--brand`, иконка WA. Не перекрывает контент (нижний отступ страницы = высота CTA + safe-area).

## 4. Соцсети
`site.json → socials`: Instagram, TikTok, Threads — чистые URL без трекинговых параметров (`?stkn`, `igshid`, `_r`, `_t` не копировать).
- В талоне под менеджерами, над перфорацией: заголовок mono `socials.title`, ряд из 3 одинаковых пилюль (иконка + название), каждая — внешняя ссылка `target="_blank" rel="noopener"`. На 360px все три в один ряд (при нехватке места — только иконки 48px с `aria-label`).
- Иконки — простые монохромные SVG, нарисованные вручную или из `simple-icons` (npm, только 3 нужные иконки импортом по одной). Официальные цвета брендов не используем — всё в палитре сайта.

- Шапка: `mark-s` 28px + `wordmark-abroad` высотой 14px в одну строку, цвет `--text`. Подпись-tagline под ним на мобильном **убрать** (в v1 обрезалась «…за рубеж…»); на десктопе оставить.

## 7. Анимации — не мешают действию
- **Вступительную анимацию убрать.** Все интерактивные элементы видимы и кликабельны с первого кадра. Разрешены только появления ≤ 400 мс (opacity/transform), которые не блокируют клики и не сдвигают раскладку.
- Табло, глобус, самолётик, тилт — остаются.
- Звук — как в v1 (выключен по умолчанию). Щелчок при штамповке убрать вместе с интро.
