# 06 — Цвета v3: «дофаминовая» палитра (приоритет выше 01–05 во всём, что касается цвета)

Живая версия: https://s-abroad.asia/

## Задача клиента
> «Концепт хороший, его не меняем. Цвета — более яркие и дофаминовые, но не по-детски. Органично, без нежности».

**Меняем только цвет и то, как он наложен** (заливки, обводки, тени, свечения). Раскладку, тексты, шрифты, размеры, порядок блоков, логику, анимации, кредит в футере — **не трогать**. Если в коде есть правки, сделанные после v2 (например, шрифты Montserrat / IBM Plex Mono, блок «Create by…»), — сохранить как есть.

Эталон цвета — `docs/ref/palette-desktop.png` и `docs/ref/palette-mobile.png`. Это **схематичный макет только для цвета**: раскладка, шрифты, иконки-эмодзи и QR на нём условные, их не копировать.

## Что сейчас «нежное» (снято с живого сайта)
`--ink #07120c` (почти чёрный фон), `--gold #e4b96a` (пыльное золото), `--mint #8ed1a6` (пастельная мята), `--paper #f3efe6` (кремовая бумага), `--muted #8fa097` (серо-зелёный), мягкие размытые тени и свечения, полупрозрачные обводки. Всё это уходит.

## Принципы (почему ярко, но по-взрослому)
1. **Цвет — полем, а не акцентом.** Фон страницы — насыщенный изумруд, а не чёрный.
2. **Мало оттенков, каждый на своём месте.** Основная пара — изумруд + кислотный лайм. Розовый — «специя». Оранжевый и фиолетовый живут только в штампах и аватарах.
3. **Чёрный и чистый белый — якоря.** Чёрные обводки 2px, чёрный текст на ярком, чистый белый талон. Именно чёрный делает яркое взрослым.
4. **Плоско и жёстко.** Сплошные заливки на 100%. Никаких пастелей, градиентов между цветами, размытых цветных свечений, полупрозрачных «стеклянных» слоёв. Тень — сплошная со смещением, без blur.
5. **Никогда цвет на цвете без проверки.** Розовый/оранжевый/фиолетовый не кладём на зелёный фон как текст или тонкую линию (контраст розового на зелёном 1.7:1) — только диском с чёрной обводкой или на чёрном/белом.

## Токены (заменить в `@theme` / `:root`)
```css
/* поле */
--field:      #00754A;  /* фон страницы: насыщенный изумруд */
--field-2:    #00643F;  /* низ/края фона, вырезы перфорации */
--field-line: #0A8F5C;  /* тонкие линии и бордеры на поле */
/* якоря */
--ink:        #0B0B0B;  /* чёрный: обводки, текст на ярком, панели */
--white:      #FFFFFF;  /* талон, текст на поле */
--on-field-2: #CFEBDD;  /* вторичный текст на поле (вместо --muted) */
--paper-muted:#4A4A4A;  /* вторичный текст на белом */
--paper-line: #E6E6E6;  /* разделители на белом */
/* дофамин */
--lime:       #D2FF3A;  /* главный акцент и действие */
--pink:       #FF3D7F;  /* специя */
--orange:     #FF7A1A;  /* только штамп */
--violet:     #6A4DFF;  /* только штамп и аватар */
```
Удалить: `--gold`, `--mint`, `--paper #f3efe6`, `--paper-2`, `--muted`, `--brand`, `--brand-hi`, старые `--ink #07120c`, `--ink-2`, `--ink-3`. Если токен нужен коду по имени — переопредели значение, но в итоговом CSS не должно остаться старых hex (тест в конце).

Фон страницы: `radial-gradient(120% 90% at 20% 0%, var(--field) 0%, var(--field-2) 70%)` — один оттенок в другой, без чужих цветов. Зерно (grain) оставить, opacity ≤ .04.

Логотипный зелёный клиента `#195231` остаётся только внутри favicon/иконок/OG как фон знака — на странице его больше нет: поле `#00754A` — это тот же зелёный, «выкрученный» по насыщенности.

## Штампы — «наклейки»
Теперь это **залитые диски**, а не контурные кольца. Требования к чёткости из 05 (без фильтров, поворот внутри SVG, целые размеры) остаются.
- Диск со сплошной заливкой + чёрное кольцо 4 ед. по краю + тонкое чёрное кольцо 1.5 ед. внутри. Иконка и текст по кругу — `--ink`.
- Цвета по порядку: Поступление — `--lime`, Языки — `--pink`, Каникулы — `--orange`, Визы — `--violet` (на фиолетовом иконка, кольца и текст по кругу — `--white`: чёрный на нём даёт только 3.9:1).
- «Выщерблины» из 05 делать цветом поля в маске, не полупрозрачностью.
- Подписи под штампами — `--white`.
- Никакого свечения и тени вокруг диска.
