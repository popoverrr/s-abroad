## Визуальный чек-лист
- [ ] Первое впечатление: «дорого и живо», а не шаблон link-in-bio. Если сомневаешься — усиливай типографику и воздух, а не добавляй эффекты.
- [ ] 1280×800 и 1920×1080: всё на одном экране без скролла, талон целиком виден.
- [ ] 360px: табло в одну строку, ничего не обрезано, нет горизонтального скролла (проверь `document.documentElement.scrollWidth <= innerWidth` в скрипте).
- [ ] Казахский слоган и лейблы не ломают вёрстку (длиннее русского!).
- [ ] Глобус не перекрывает текст по читаемости, маркеры видны.
- [ ] Перфорация талона чистая, вырезы цвета фона, без артефактов на краях.
- [ ] Штампы выглядят «чернильно», не как плоские кружки.
- [ ] Sticky CTA на мобиле не перекрывает последнюю строку футера (есть нижний отступ под него).
- [ ] Фокус с клавиатуры виден на всех интерактивных элементах, порядок Tab логичный.

## Функциональный чек-лист (проверь скриптом или вручную в Playwright)
- [ ] Переключение 4 языков меняет все тексты, `<html lang>`, title, `?lang=`; перезагрузка сохраняет язык.
- [ ] Все ссылки-выходы имеют правильные href по правилам `docs/03-tech.md`; TODO → `#todo`.
- [ ] WhatsApp-ссылка содержит сообщение на текущем языке; у штампов — своё сообщение.
- [ ] vCard скачивается, валиден (открой содержимое, проверь BEGIN/END, FN, TEL без TODO).
- [ ] «Поделиться» без Web Share API копирует ссылку и показывает toast.
- [ ] QR ведёт на домен из site.json (или текущий origin, если домен TODO) и сканируется (декодируй, если есть лёгкий способ — например `jsqr` в dev-скрипте; иначе проверь, что строка в генератор передана верно).
- [ ] Звук: по умолчанию выключен, по клику включается «динь-дон», табло щёлкает, состояние помнится.
- [ ] Интро один раз за сессию; клик пропускает.
- [ ] `prefers-reduced-motion: reduce` (эмуляция в Playwright) — без интро, без перебора букв, без тилта, всё видно сразу.
- [ ] WebGL выключен (`--disable-webgl`) → fallback-глобус, без ошибок.
- [ ] В консоли продакшн-сборки 0 ошибок.
