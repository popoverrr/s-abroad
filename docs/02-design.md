# 02 — Дизайн

## Концепция: «Посадочный талон в Европу»
Тёмная «ночная взлётка» + светлый бумажный посадочный талон. Сайт ощущается как момент перед вылетом: табло перещёлкивает города, глобус медленно вращается, на талоне — ваши «выходы на посадку» (контакты). Премиально, спокойно, с парой вау-моментов, а не цирк.

## Токены
```css
--ink:        #0A0D14;   /* фон */
--ink-2:      #121726;   /* панели, табло */
--ink-3:      #1C2233;   /* бордеры на тёмном */
--text:       #EDEAE3;   /* текст на тёмном */
--muted:      #8A8FA3;   /* вторичный на тёмном */
--paper:      #F4EFE6;   /* талон */
--paper-2:    #E7DFCF;   /* линии/перфорация на талоне */
--paper-ink:  #14161C;   /* текст на талоне */
--paper-muted:#6B6A66;
--accent:     #FF5B24;   /* runway orange — CTA, стрелки, маркеры */
--accent-2:   #2F6BFF;   /* passport blue — штампы, фокус */
--flap:       #FFC247;   /* янтарь табло */
--success:    #2BD17E;   /* «Посадка открыта» точка */
```
Радиусы: талон 28px (desktop) / 24px (mobile); кнопки 999px; штампы — круг.
Тени талона: `0 40px 80px -20px rgb(0 0 0 / .6), 0 0 0 1px rgb(255 255 255 / .04)`.
Зерно: SVG feTurbulence поверх всего, opacity .05, `pointer-events:none`, mix-blend overlay.

## Шрифты (через @fontsource, variable где есть)
- Display: **Unbounded** (700–800) — слоган, бренд.
- Body/UI: **Onest** (400–600).
- Mono: **JetBrains Mono** (500) — табло, номера выходов, коды городов, подписи в талоне.
Обязательно проверь, что есть глифы казахского (ә ғ қ ң ө ұ ү һ і) и чешского (ě š č ř ž ý ů). Если у шрифта нет — замени на ближайший с покрытием (Manrope / Inter / Golos) и отметь в отчёте.

Шкала:
- Слоган: `clamp(48px, 9vw, 128px)`, line-height .92, letter-spacing -0.03em, uppercase не нужен.
- Eyebrow / лейблы: mono 11–12px, uppercase, letter-spacing .14em, `--muted`.
- Строки ссылок: 17–20px Onest 500.

## Раскладка

### Desktop ≥ 1024px — один экран 100svh, без скролла на 1280×800 и выше

Сетка 12 колонок, поля 48–72px. Левая часть 7 колонок, талон 5 колонок (max 460px), выровнен по центру вертикали.
Глобус: canvas ~ 900px, позиция `right: 30%; bottom: -35%`, частично уходит за край и под талон, opacity .9, z-index ниже текста.

### Tablet 768–1023
Две колонки сохраняются, но слоган меньше, штампы переносятся под табло в 2×2, глобус 600px. Допустим вертикальный скролл.

### Mobile < 768 — mobile-first, это основной трафик из Instagram
Порядок сверху вниз:
1. Топ-бар (sticky не нужен): знак + S ABROAD слева; справа компактный язык (текущий код, по тапу выпадает 4 варианта) и иконка звука.
2. Глобус 320px в правом верхнем углу за слоганом, opacity .55.
3. Eyebrow → слоган (≈ 52–60px на 390px) → подстрочник.
4. Табло (одна строка, горизонтально помещается на 360px — проверь!).
5. Талон на всю ширину (поля 16px). В талоне ссылки-выходы. Корешок: вместо QR — две большие кнопки «Сохранить контакт» и «Поделиться» + текстовая ссылка «Показать QR другу» → модалка с QR на весь экран (белый фон, ярко).
6. Штампы: горизонтальная прокрутка со scroll-snap, видно 2,3 штампа (намёк на свайп).
7. Футер.
8. **Sticky CTA** снизу: оранжевая pill-кнопка «Бесплатная консультация» + иконка WhatsApp, `padding-bottom: env(safe-area-inset-bottom)`, на подложке с blur. Появляется после того, как первая ссылка-выход ушла из вьюпорта (IntersectionObserver), чтобы не дублировать.
Тап-зоны ≥ 48px. Никакого горизонтального скролла страницы.

## Компоненты

### TopBar
Знак (`assets/mark.svg`, 28px) + «S ABROAD» (Unbounded 700, 15px, letter-spacing .08em) + под ним `brand.tagline` мелким muted.
Языки: 4 кнопки mono 12px, активный — `--text` с подчёркиванием-точкой `--accent`, остальные `--muted`. `aria-pressed`.
Звук: иконка-эквалайзер (3 полоски анимируются, когда включён) + подпись `sound.on/off` (на мобиле — только иконка, подпись в aria-label).

### Hero
Eyebrow с пульсирующей зелёной точкой. Слоган — 3 строки из `hero.title_lines`; последнее слово «кампус.» с точкой цвета `--accent`. Подстрочник — `hero.subtitle` через « · ».

### DepartureBoard (табло)
Пилюля `--ink-2`, бордер `--ink-3`, радиус 14px, mono.
Содержимое: `ALMATY` → иконка самолёта → **город назначения** в перекидных ячейках (split-flap) → время → статус с зелёной точкой.
- Каждая буква — отдельная ячейка 0.9em×1.3em, фон `#0E1220`, горизонтальная линия-стык посередине, текст `--flap`.
- Список городов — `site.json → destinations` (латиница, как на табло: PRAHA, BRNO, WIEN, BERLIN, MILANO, WARSZAWA, BUDAPEST, LONDON). Длина ячеек = максимальная длина, пустые — пробел.
- Смена каждые 3,2 с. Анимация буквы: перебор 3–6 случайных символов по 45 мс, затем целевой; flip через rotateX верхней половинки (CSS 3D). Задержка между ячейками 40 мс слева направо.
- Время — случайное HH:MM из диапазона 06:00–23:55 при каждой смене (просто визуал).
- Со звуком: на каждый «щелчок» — короткий клик (см. «Звук»), громкость низкая, не чаще 1 клика/30 мс.
- reduced-motion: мгновенная смена текста с fade.

### Globe
Библиотека **cobe** (WebGL, ~5 КБ). Тёмная тема: `dark: 1`, `baseColor: [0.16,0.18,0.25]`, `markerColor: [1, 0.36, 0.14]` (accent), `glowColor: [0.18,0.22,0.35]`, `mapBrightness: 5`, `diffuse: 1.2`, `mapSamples: 16000`, `devicePixelRatio: min(2, dpr)`.
Маркеры: Алматы (43.24, 76.89) крупный; города из `destinations` с координатами из `site.json`.
Стартовый поворот так, чтобы между Алматы и Прагой был виден центр (phi ≈ 0.9, theta ≈ 0.3). Автовращение 0.0025 рад/кадр; drag мышью/пальцем крутит (с инерцией). Когда табло показывает город — его маркер кратко увеличивается (size ×1.8 на 600 мс).
Если версия cobe поддерживает дуги (`arcs`) — нарисуй дугу Алматы → текущий город цветом accent. Если нет — не городи хаков, только маркеры.
Пауза рендера, когда вкладка скрыта или глобус вне вьюпорта. Если WebGL недоступен — статичный SVG-круг с точками (fallback).
Под глобусом мягкое радиальное свечение `--accent` opacity .12.

### BoardingPass (талон) — сердце сайта
Бумага `--paper`, текст `--paper-ink`. Структура:
1. Шапка: mono `pass.title` слева, знак + S ABROAD справа. Тонкая линия.
2. Маршрут: `ALA` крупно (Unbounded 40px) — пунктирная линия с самолётом по центру (самолёт медленно «летит» туда-обратно по пунктиру, 6 с, ease-in-out) — `EUR` крупно. Под кодами mono-подписи `pass.from_city` / `pass.to_city`.
3. Мета-строка в 3 колонки (mono): `Пассажир — Вы`, `Класс — Студент`, `Посадка — Сейчас` (`pass.*`).
4. **Выходы (ссылки)** — список `links` из `site.json`, только enabled и не пустые. Строка: номер `01` (mono, accent), лейбл (i18n) + под ним мелкий handle/номер телефона (paper-muted), справа стрелка ↗ в круге 36px.
   - Hover (desktop): строка заливается `--paper-ink` снизу вверх (clip-path, 250 мс), текст становится `--paper`, стрелка — `--accent` и смещается на 3px вверх-вправо. Лёгкий магнитный эффект стрелки к курсору.
   - Active (mobile): scale .98 + заливка.
   - Первая ссылка — главная (WhatsApp-консультация), у неё лейбл жирнее и маленький бейдж `badge.free` («бесплатно»).
5. **Перфорация**: полукруглые вырезы по краям (radial-gradient маска или два круга цвета фона `--ink`) + пунктир `--paper-2` посередине.
6. **Корешок**:
   - Desktop: QR (SVG, цвет `--paper-ink` на `--paper`, 112px, внутри в центре маленький знак) + текст `stub.scan` + две кнопки-пилюли «Сохранить контакт» / «Поделиться».
   - Mobile: две большие кнопки в ряд + ссылка «Показать QR другу».
   - Внизу корешка — декоративный штрих-код (генерируется из строки бренда, чисто визуально) и mono `S-ABROAD · 2026 · SEAT 01A`.
Desktop-интерактив: 3D-тилт по курсору (max 6°, perspective 1200px, spring), блик — радиальный градиент белого 10%, следует за курсором. На мобильном тилт от `deviceorientation` только если разрешение уже есть (на iOS не проси) — иначе без тилта.

### Stamps (услуги)
4 штампа из `services` (i18n): круглый SVG 132px (mobile 116px) — двойное кольцо, текст по окружности (`textPath`), в центре иконка (линейная, 1.5px: шапка выпускника, речевое облачко, солнце/чемодан, паспорт) и короткое название. Цвета чередуются `--accent` / `--accent-2`, лёгкая «чернильная» неровность: SVG-фильтр feTurbulence+feDisplacementMap (scale 1.5), opacity .9, случайный поворот −12°…+12° (детерминированный по индексу, без рассинхрона SSR).
Появление: по очереди «штампуются» — scale 1.35→1, opacity 0→1, spring, с глухим «тук» при звуке.
Hover: поворот к 0°, подсказка с `services[i].text`. Клик: WhatsApp с `services[i].wa` сообщением.
На desktop штампы лежат на тёмном фоне под табло (тёмная версия: штамп светится своим цветом).

### ShareSheet / QR Modal / Toast
- «Поделиться»: `navigator.share({title, text, url})`; если нет — копирование ссылки + toast `stub.copied`.
- «Сохранить контакт»: сгенерируй vCard 3.0 (FN S ABROAD, ORG, TEL из site.json, URL сайта, X-SOCIALPROFILE instagram, NOTE — tagline), скачай `S-ABROAD.vcf`. TODO-значения в vCard не включай.
- QR-модалка: белый фон, QR 70vmin, под ним домен, закрытие по тапу/Esc, focus trap.

### Footer
Слева `footer.left` (S ABROAD · 2026 · …), справа ссылка на филиал в Украине (`footer.ukraine`), если он enabled. Mono 11px muted.

## Моушн
Вводная (один раз за сессию, `sessionStorage`, суммарно ≤ 1,6 с, пропускается кликом):
1. 0–400 мс: фон + зерно, табло прокручивает буквы и складывает `S ABROAD`, затем уходит в первый город.
2. 200–900: строки слогана выезжают из-под маски снизу (stagger 90 мс, ease `[0.22,1,0.36,1]`).
3. 500–1300: талон «печатается» — clip-path сверху вниз + лёгкий сдвиг по Y 24px→0; перфорация появляется последней.
4. 900–1600: штампы штампуются по одному; глобус проявляется (opacity 0→1, scale .96→1).
Повторный визит в сессии — всё сразу, без интро.
Всегда: только transform/opacity/clip-path, 60 fps на среднем Android. `prefers-reduced-motion` → без вводной, без тилта, глобус без автовращения, табло без перебора.

## Звук (WebAudio, без аудиофайлов)
Выключен по умолчанию; состояние в `localStorage`. AudioContext создаётся только по клику.
- Щелчок табло: белый шум 12 мс через bandpass 2–3 кГц, огибающая 1→0, gain .05, рандом pitch ±10%.
- Включение звука: мягкий аэропортовый «динь-дон» — две синусоиды (E5 → C5), 180 мс каждая, с лёгким реверб-хвостом (ConvolverNode на сгенерированном импульсе) gain .12.
- Штамп: низкий «тук» — синус 110 Гц с быстрым спадом 90 мс + щелчок.
- Hover по выходу (desktop): едва слышный тик, gain .02, throttle 80 мс.

## Доступность
Контраст AA на обоих фонах; видимый фокус (2px `--accent-2` outline, offset 3px); все декоративные штуки `aria-hidden`; табло имеет `aria-live="off"` и скрытый текст «Направления: …»; языковые кнопки с `lang` и `hreflang`-смыслом; ссылки наружу `target="_blank" rel="noopener"`, WhatsApp/tel — без target.
