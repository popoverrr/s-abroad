# 09 — Звук всегда включён, переключатель на экране языка убрать (v6)

Приоритет выше `docs/08-language-gate-v5.md` во всём, что касается звука и показа экрана выбора языка. Где 08 противоречит этому документу — прав этот.

## Что сказал клиент
> Зачем эта кнопка снизу? Мне нужно, чтобы звук по умолчанию ВСЕГДА был включён и чтобы это везде корректно работало. Включение звука привязано к любой кнопке выбора языка. Выключается звук только кнопкой на сайте, которая уже есть.

## Что сделать

### 1. Убрать переключатель звука с экрана выбора языка
Удалить пилюлю «ЗВУК · SOUND · ДЫБЫС» со свитчем полностью: разметку, стили, состояние, обработчики, aria-тексты, ключ `sound` из `gate.json` (в архиве `content/gate.json` уже без него — скопируй в проект и в `src/content/`). На экране остаются: логотип, табло, подпись, три кнопки языка. Блок отцентрировать по вертикали заново.

### 2. Любая кнопка языка включает звук — без условий
В синхронном обработчике клика по **любой** из трёх кнопок (и по Enter/Space на них, и по Esc):
1. создать общий `AudioContext`, если его нет, и вызвать `resume()` — прямо в обработчике, до любых `await`/`setTimeout` (требование iOS Safari);
2. выставить состояние звука сайта = **вкл**;
3. сыграть приветственный «динь-дон»;
4. дальше — как в 08: применить язык, закрыть экран, запустить таймеры.
Никаких проверок «а не выключал ли пользователь звук раньше».

### 3. Экран выбора языка — при каждом заходе
Чтобы звук работал «всегда и везде», клик нужен при каждом открытии страницы (браузеры не дают звук без клика). Поэтому:
- экран показывается **при каждой загрузке страницы**, а не только при первом визите;
- ранее выбранный язык (из `localStorage`) подсвечен лаймом и получает начальный фокус; если сохранённого нет — подсвечен язык по `navigator.languages`, как раньше;
- исключения, когда экран не показывается: `?og=1` и явный `?lang=ru|en|kk` в адресе (нужно для автотестов и прямых ссылок). В этих случаях звук считается включённым и запускается на первом касании страницы (одноразовый слушатель `pointerdown`/`keydown`/`touchend`, как описано в 08).
- Сам сайт после выбора языка **не** должен дописывать `?lang=` в адресную строку (иначе при обновлении страницы экран пропадёт и звук не запустится). Язык хранить только в `localStorage`. Если v5 уже пишет `?lang=` через `replaceState` — убрать это.

### 4. Звук выключается только кнопкой в шапке сайта
- Кнопка звука в шапке — единственный способ выключить звук. Работает как сейчас.
- Выключение действует **до перезагрузки страницы**. Состояние звука больше **не сохранять** в `localStorage` и не читать оттуда; старый сохранённый ключ звука удалить/игнорировать. При следующем заходе звук снова включён.
- Кнопка в шапке после выбора языка всегда показывает «вкл».
- Подсказку «кнопка звука мигает при вылете самолётиков» оставить только для случая, когда пользователь выключил звук в этой сессии.

### 5. Проверить, что звук реально слышен везде
Пройди по всем местам, где сайт издаёт звук, и убедись, что каждый использует **один общий** `AudioContext` и проверяет одно и то же состояние «вкл/выкл»:
- приветственный «динь-дон» при выборе языка;
- щелчки табло;
- свист пролёта самолётиков на 7-й секунде (`soundEnabled`, `getAudioContext` в `initPlaneEgg`);
- звук поимки самолётика;
- прочие (hover-тики и т.п.).
Частые причины «звук включён, но тишина» — проверь каждую:
- `AudioContext` создаётся в `useEffect`/после `await`, а не в обработчике клика → на iOS остаётся `suspended`;
- у модуля пасхалки свой контекст вместо общего;
- после возврата на вкладку контекст `suspended`/`interrupted` → на `visibilitychange` (visible) и на любом `pointerdown` вызывать `resume()`, если звук включён;
- громкость мастер-гейна осталась 0 после прошлого выключения.

## Чего не делать
- Не добавлять никаких других переключателей, подсказок и текстов про звук.
- Не менять внешний вид кнопок языка, табло, сайта.
- Не обходить запрет автовоспроизведения трюками (скрытый `<audio autoplay>` и т.п.).

## Приёмка v6
Автотесты (Playwright; для проверки звука — тестовый хук `window.__audioState()` → `{ state, enabled }`):
- [ ] На экране языка нет элемента со свитчем: `[role="switch"]` — 0 штук; в DOM и `dist/` нет строк «ЗВУК · SOUND», «Дыбыс қосулы».
- [ ] Клик по каждой из трёх кнопок (три отдельных прогона) → `enabled === true`, `state === 'running'`.
- [ ] То же через клавиатуру (Enter на кнопке) и Esc.
- [ ] Перезагрузка страницы после выбора языка → экран языка показан снова, ранее выбранный язык подсвечен; в адресе нет `?lang=`.
- [ ] Выключить звук кнопкой в шапке → `enabled === false`; перезагрузка → выбор языка → `enabled === true`.
- [ ] `localStorage` не содержит ключа состояния звука.
- [ ] После выбора языка через ~7 с вылетают самолётики, и в момент вылета `state === 'running'`, `enabled === true`.
- [ ] Скрыть и вернуть вкладку (эмуляция `visibilitychange`) → после возврата `state === 'running'`.
- [ ] `?lang=ru`: экрана нет, `enabled === true`; после первого `pointerdown` — `state === 'running'`.
- [ ] Экран языка без скролла на 360×640, 390×844, 1280×800; блок по центру.
- [ ] Старые автотесты (с `?lang=ru`) зелёные; в консоли 0 ошибок.

Глазами: скриншоты экрана языка на 360×640, 390×844, 1280×800 в `screenshots/gate-v6-*.png` — посмотри сам, свитча нет, блок по центру.

Вручную на телефоне проверить нельзя из автотестов — в отчёте напомни клиенту проверить звук на iPhone (Safari и браузер Instagram) и Android (Chrome): на iPhone звук не играет, если включён беззвучный режим переключателем на корпусе, — это ограничение устройства, не баг.
