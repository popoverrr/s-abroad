# 08 — Экран выбора языка, звук по умолчанию, три языка (v5)

Живая версия: https://s-abroad.asia/

## Что хочет клиент
> Кнопка выбора языка при заходе, и чтобы звук по умолчанию был включён (если не получается — кнопка выбора языка как раз закрывает этот момент: происходит клик, и по нему включается звук). Языки: русский, английский, казахский.

Три задачи:
1. Экран выбора языка при входе («гейт»).
2. Звук включён по умолчанию; первый клик по языку запускает его.
3. Языков три: RU, EN, KZ. Чешский убрать.

Эталон вида — `docs/ref/gate-ref.png` (десктоп 1280, мобильный 390 и 360). Это схема: шрифты и логотип бери из проекта. **Недочёт эталона, не повторять:** на мобильном надпись на табло переносится на вторую строку — в проекте она должна быть в одну (см. ниже).

## 1. Экран выбора языка

### Когда показывать
- Показывать, если язык **не выбран явно**: нет сохранённого языка в `localStorage` и нет валидного `?lang=` в адресе.
- Не показывать: вернувшимся посетителям (язык сохранён), при `?lang=ru|en|kk` и при `?og=1`. Отдельной логики для ботов и автотестов не делать: старым тестам передавай `?lang=ru`.
- `?gate=1` — показать принудительно (для отладки и тестов).
- Решение «показывать или нет» принимается **синхронно до первого рендера** (в начальном состоянии, не в `useEffect`), чтобы сайт не мигал перед гейтом.

### Как устроен
- Полноэкранный слой поверх сайта: `position: fixed; inset: 0`, фон — тот же, что у страницы (`--field` → `--field-2`), **непрозрачный**. Сайт под ним отрендерен (для SEO и скорости), но помечен `inert` и `aria-hidden`.
- `role="dialog"`, `aria-modal="true"`, `aria-label` из `content/gate.json → dialog_aria`. Фокус-ловушка. Начальный фокус — на кнопке предугаданного языка.
- Содержимое по центру, колонка шириной до 440px, поля 16px:
  1. **Логотип** S ABROAD (из `assets/brand`, белый).
  2. **Табло** — существующий компонент split-flap на чёрной плашке: по кругу каждые 2,2 с перекидывает `gate.json → board` («ВЫБЕРИТЕ ЯЗЫК» → «CHOOSE LANGUAGE» → «ТІЛДІ ТАҢДАҢЫЗ»). На мобильном убрать префикс `ALMATY ✈` и/или уменьшить ячейки так, чтобы самая длинная строка (15 символов) помещалась **в одну строку на 360px**. Ширина табло фиксирована по самой длинной строке — без прыжков.
  3. **Подпись** мелким mono: `gate.json → caption` (статичная, все три языка сразу — для тех, кто не ждёт табло; она же текст для скринридера, табло — `aria-hidden`).
  4. **Три кнопки языка** в столбик, в порядке `gate.json → languages`: Русский, English, Қазақша. Каждая: высота 68px (64 на 360px), белая, обводка 2px `--ink`, радиус 18px, жёсткая тень `5px 6px 0 var(--ink)`; слева чёрная пилюля с кодом (RU / EN / KZ, mono), название языка крупно (800, 21px), справа круг со стрелкой →. Атрибут `lang` на каждой кнопке.
     - **Предугаданный язык** (по `navigator.languages`: `kk*` → kk, `en*` → en, всё остальное → ru) залит `--lime`, его стрелка — в чёрном круге. Остальные — белые.
     - Hover/focus: заливка `--lime`; active: тень 0 и сдвиг `translate(5px,6px)`.
  5. **Переключатель звука** — чёрная пилюля: иконка-эквалайзер, `gate.json → sound.label`, свитч. По умолчанию **включён**. Это `button role="switch"` с `aria-checked`. Позволяет войти без звука.
- Весь гейт помещается **без скролла** на 360×640 и 1280×800.
- Глобус на фоне гейта не нужен (экономим старт) — достаточно фона и зерна.

### Что происходит по клику на язык
В **одном синхронном обработчике клика** (это важно для iOS Safari — звук разрешается только внутри обработчика жеста):
1. Создать/возобновить общий `AudioContext` сайта (`resume()`), если свитч звука включён.
2. Сохранить язык (`localStorage`), применить его (`<html lang>`, title, meta, `?lang=` через `replaceState`).
3. Сохранить состояние звука (вкл/выкл по свитчу).
4. Сыграть приветственный «динь-дон» (существующий звук включения), если звук включён.
5. Закрыть гейт: анимация ≤ 450 мс — слой уезжает вверх (`translateY(-100%)`, ease `[0.7,0,0.2,1]`), под ним уже готов сайт. При `prefers-reduced-motion` — мгновенно.
6. Снять `inert`, вернуть фокус на `<main>` (или первую кнопку талона), удалить гейт из DOM.
7. **Только теперь** стартуют: таймер пасхалки (7 с — `initPlaneEgg`), перекидывание табло на сайте, автовращение глобуса. Пока гейт открыт, они стоят.

Клавиатура: Enter/Space на кнопке — то же, что клик. Esc — выбрать предугаданный язык (с учётом свитча звука).

## 2. Звук по умолчанию включён
- Состояние звука по умолчанию — **вкл**. Если пользователь сам выключил (на гейте или кнопкой в шапке) — запомнить `off` и уважать при следующих визитах.
- **Новый посетитель** проходит гейт → клик → звук работает сразу, включая свист самолётиков на 7-й секунде.
- **Вернувшийся посетитель** гейт не видит, а браузер запрещает звук до первого действия. Поэтому: состояние «вкл», кнопка звука в шапке показывает «вкл», а `AudioContext` создаётся/возобновляется на **первом** `pointerdown` / `keydown` / `touchend` где угодно на странице (одноразовый слушатель, `capture: true`). До этого момента звуки молча пропускаются — без ошибок в консоли и без очереди «догоняющих» звуков. Приветственный «динь-дон» в этом случае не играть.
- Не пытайся обойти запрет автовоспроизведения (никаких скрытых `<audio autoplay>`, muted-трюков и т.п.).
- Громкость держи скромной: щелчки табло ≤ 0.05, свист пролёта ≤ 0.07, перезвоны ≤ 0.13 — как сейчас. Раз звук теперь включён по умолчанию, проверь, что **щелчки табло не раздражают**: не чаще одного пакета щелчков на смену города, без щелчков на вкладке в фоне.
- Подсказка «кнопка звука мигает при вылете самолётиков» (из 07) остаётся для случая, когда звук выключен пользователем.

## 3. Три языка: RU, EN, KZ
- Удалить чешский: `content/i18n/cs.json` и копию в `src/content`, код `CZ` в шапке, ветки определения языка (`cs*`, `sk*`), `og:locale:alternate`, hreflang, типы. `?lang=cs` и сохранённый `cs` в `localStorage` → трактовать как «язык не выбран» (показать гейт).
- В шапке остаются три кода. Порядок в шапке — как на гейте: **RU · EN · KZ**.
- Города на табло (PRAHA, BRNO…) не трогать — это направления, а не язык интерфейса.
- В `egg/i18n-egg.json` чешского уже нет.

## Чего не делать
- Не менять раскладку, цвета, шрифты, тексты сайта, контакты, кредит в футере.
- Не добавлять на гейт ничего лишнего: ни слоганов, ни cookie-текстов, ни «пропустить».
- Не показывать гейт повторно тем, кто уже выбрал язык.
- Никаких `filter`/`blur`, новых библиотек.
