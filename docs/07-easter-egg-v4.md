# 07 — Пасхалка «поймай самолётик» (v4)

Живая версия: https://s-abroad.asia/

## Что хочет клиент
> Через 7 секунд после открытия пролетают самолётики (со звуком). Качественная прикольная анимация-пасхалка в стиле сайта. Если самолётик ловится — открываются контакты с логичным для пасхалки текстом. Качественно и детализированно.

## Что уже сделано — в `egg/`
Анимация **написана и проверена в браузере**. Твоя задача — встроить, а не переписывать.
- `egg/plane-egg.ts` — модуль без зависимостей (strict TypeScript проходит): планировщик, траектория, три самолётика, след, поимка, конфетти, штамп, звук (WebAudio).
- `egg/plane-egg.css` — стили слоя.
- `egg/plane-white.svg`, `plane-lime.svg`, `plane-pink.svg` — те же самолётики отдельными файлами (для справки и OG; в модуле они уже встроены).
- `egg/i18n-egg.json` — тексты на RU / KZ / EN / CZ.
- `egg/demo/` — рабочее демо (`demo.html`, открыть двойным кликом). **Фон там условный**, смотреть только на самолётики.

### Как это выглядит
- Звено из трёх бумажных самолётиков, сложенных из посадочного талона (на крыле полоса, перфорация, штрих-код): белый ведущий, лаймовый и розовый ведомые.
- Десктоп: вылетают слева снизу, делают мёртвую петлю над слоганом и уходят вверх, **не заходя на талон**. Мобильный: летят слева направо в полосе над талоном, тоже с петлёй.
- За каждым — пунктирный след, как линия маршрута на талоне; исчезает за секунду. Плоская чёрная тень со смещением, без blur.
- Поимка (тап/клик): самолётик «лопается», разлетаются обрывки талона и звёздочки в цветах сайта, на месте поимки бьётся круглый штамп «ПОЙМАН», остальные два самолётика удирают. Через 0,7 с вызывается `onCatch()`.
- Если не поймали — повтор через 40 с, всего 3 вылета за загрузку страницы. После поимки вылетов больше нет.

## Встраивание
1. Скопируй `egg/plane-egg.ts` и `egg/plane-egg.css` в проект (например `src/egg/`), импортируй CSS.
2. Добавь ключ `egg` из `egg/i18n-egg.json` в каждый `content/i18n/<lang>.json` и в копию в `src/content/`. Обнови типы i18n. Остальные ключи не трогай.
3. Вызови `initPlaneEgg(...)` **один раз** после монтирования приложения (в `useEffect` корневого компонента, с `destroy()` в cleanup — важно для StrictMode):

```ts
const egg = initPlaneEgg({
  firstDelayMs: 7000,
  onCatch: () => openChooser({ variant: 'egg' }),
  isBlocked: () => chooserOpen || anyDialogOpen,
  soundEnabled: () => soundOn,            // состояние переключателя «Звук» на сайте
  getAudioContext: () => siteAudioCtx,    // общий AudioContext сайта, если он уже создан; иначе null
  avoid: () => [passEl, mainCtaEl, stickyCtaEl],
  onFlyby: ({ soundOn }) => { if (!soundOn) pulseSoundButton(); },
  labels: () => ({ catchAria: t('egg.catch_aria'), stamp: t('egg.stamp') }), // функция — язык может смениться
});
```
`labels`, `isBlocked`, `soundEnabled` читаются в момент вылета — передавай через ref, а не замыкай устаревшее состояние.

4. **Контакты в режиме пасхалки.** `onCatch` открывает тот же выбор менеджера, что и главная кнопка WhatsApp (bottom sheet на мобильном, на десктопе — **по центру экрана** как модалка, а не поповером у кнопки), но с другой шапкой:
   - бейдж-пилюля `egg.badge` (фон `--lime`, обводка 2px `--ink`, mono, uppercase) с маленьким самолётиком `plane-white.svg` слева;
   - заголовок `egg.title`, подзаголовок `egg.sub`;
   - те же две строки менеджеров; ссылки WhatsApp — с текстом **`egg.wa`** (с подстановкой `{name}`) вместо `wa.default`. Менеджер увидит, что человек пришёл через пасхалку.
   - Закрытие, фокус, Esc, «назад» — как у обычного выбора. После закрытия самолётики больше не летают до перезагрузки.
5. **Слои.** `.egg-layer` — `z-index` выше контента и sticky-CTA, но **ниже** диалога выбора менеджера и toast. Подгони число в CSS под реальные z-index проекта.
6. **Подсказка про звук.** `pulseSoundButton()` — кнопка звука один раз дважды «пульсирует» лаймовой обводкой (CSS-анимация 2×450 мс). Больше ничего: никаких тултипов и баннеров.
7. **Отладка.** `?egg=now` в адресе → первый вылет через 0,5 с. В dev положи хэндл в `window.__egg` (`window.__egg.launchNow()`).

## Звук — как устроено и почему
- **Свист пролёта** (шум с «доплером», панорама слева направо, усиление на петле) играет, только если звук на сайте включён. Причина не только в переключателе: браузеры запрещают воспроизведение звука до первого действия пользователя на странице, поэтому на 7-й секунде у нового посетителя звук физически не может заиграть. Не пытайся это обходить.
- **Звук поимки** (хруст бумаги → «тук» штампа → восходящий аэропортовый перезвон ми-соль-до) играет **всегда**, даже при выключенном переключателе: это прямой ответ на тап пользователя, он короткий и тихий. Это осознанное решение клиента («со звуком»).
- Если на сайте уже есть общий `AudioContext` и мастер-громкость — подключи модуль к ним через `getAudioContext`.

## Чего не делать
- Не переписывать анимацию, траекторию и рисунок самолётика «по-своему». Править модуль можно только для: исправления бага, подгонки `z-index`, шрифта штампа (`--mono`), имён CSS-переменных цветов под проект.
- Не добавлять библиотек (lottie, gsap, canvas-confetti и т.п.).
- Никаких `filter`, `blur`, свечений — правила v3 действуют.
- Не менять раскладку, цвета, тексты сайта, контакты, кредит в футере.
- Не придумывать акции и скидки «за пойманный самолётик» — тексты только из `i18n-egg.json`.

## Доступность и производительность (уже учтено в модуле — проверь, что не сломал)
- `prefers-reduced-motion: reduce` → ничего не летает; в правом нижнем углу стоит один неподвижный самолётик-кнопка (фокусируется с клавиатуры), нажатие = поимка без разлёта звена.
- Таймер 7 с считает только время, когда вкладка видима. При открытом диалоге вылет откладывается.
- Слой `pointer-events: none`; кликабельны только сами самолётики; траектория строится в обход элементов из `avoid`.
- Анимируются только `transform` и `opacity`. После пролёта в DOM не остаётся ни одного узла пасхалки, кроме пустого слоя.
- Зона попадания больше картинки (расширена на 14–18px) — по самолётику можно попасть пальцем.
